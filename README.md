# FLIX-UG downloads

`flix-ug.exe` — test build for 64-bit Windows, built from `master` commit 4ba7b40.
Includes the Netflix-style shop screen, the attendant screen, and ten demo titles with a demo trailer.

SHA-256: `f9dfed0fd1ef3722bad491a2f46d99aaa2b91620e479006eac9ef2c529332ada`

Put it in its own folder and double-click it. It is not signed, so Windows will warn about an unknown
publisher: choose More info, then Run anyway. Open the shop in Google Chrome or Microsoft Edge.
See the README on `master` for the full test steps.
